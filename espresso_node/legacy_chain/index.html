Module legacy_chain 

Source
Expand description

Chains recorded from legacy consensus (before 0.6), replayed through a query node that runs no consensus: a follower fed the recorded blocks, on an anvil that mines the recorded L1 transactions again, so the stake table, rewards and merklized state are derived by the code a live node runs. Mainnet and decaf still serve pre-0.6 data, and once legacy consensus is gone nothing else can produce it; data/legacy-chains/README.md describes the chains.

The recordings cannot be regenerated once legacy consensus is deleted; the recorder is kept on the legacy-chain-recorder branch. A change to how any recorded type deserializes has to keep reading them, as the data/v* reference vectors do.
